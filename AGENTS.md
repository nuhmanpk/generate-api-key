# AGENTS.md

Guidance for AI coding agents working **on** this repository.

## Layout

This is a monorepo for the `generateapikey` library, shipped in two languages
that must stay wire-compatible: a key, hash, code or token produced by one
must verify in the other.

```
python/   the PyPI package `generateapikey` (see python/AGENTS.md for its rules and commands)
js/       the npm package `@nuhmanpk/generateapikey` (TypeScript, Web Crypto only; see js/AGENTS.md)
spec/     SPEC.md (formats and algorithms, versioned) + vectors.json (generated from Python)
docs/     full API references (python.md, js.md)
.github/  CI: python.yml, js.yml, interop.yml (path-filtered); releases py-release.yml (tag py-v*), js-release.yml (tag js-v*)
assets/   images used by the READMEs (referenced by absolute raw.githubusercontent URLs)
```

## Cross-language rules

- **Python is the source of truth for wire formats.** `spec/SPEC.md` documents what
  the Python code does; don't change a format in one language only.
- `spec/vectors.json` is generated by `python/scripts/gen_vectors.py`. Never edit it
  by hand. Both test suites run it; CI fails if regenerating it changes the file.
- A format change needs: a spec version bump, regenerated vectors, both
  implementations updated, and CHANGELOG entries in both packages.
- No runtime dependencies in either package.
- **One version number.** `python/pyproject.toml`, `python/generateapikey/__init__.py`,
  `js/package.json` and `js/src/index.ts` (`VERSION`) always match; a test enforces it.
- **No key material in the repo.** Asymmetric vectors are verify-only (signed by keys that exist
  only in memory during generation); tests make fresh keys at run time. Never commit `.pem` files.
- README and docs links are absolute GitHub URLs (relative links break on PyPI and npm pages).
- `LICENSE`, `SECURITY.md` and `CONTRIBUTING.md` live at the root and are copied into
  `python/` (the sdist can't include files above its project dir); `LICENSE` is also copied
  into `js/`. Edit the root copy
  and re-copy; `python/tests/test_compat.py` checks they match.
